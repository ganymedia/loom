# Contributing to LOOM

LOOM is not accepting external code contributions or pull requests at this
time. Maintainers are still stabilizing the project and are not yet able to
provide the review and support process that outside contributions require.

You can still help by using the structured GitHub issue forms to:

- [report a bug](https://github.com/ganymedia/loom/issues/new?template=bug_report.yml)
- [request a feature](https://github.com/ganymedia/loom/issues/new?template=feature_request.yml)

GitHub issues are public. Do not include secrets, backend URLs, configuration
files, raw logs, prompts, model output, controlled unclassified information
(CUI), or other sensitive data. Follow the sanitization instructions in the
selected issue form.

Unsolicited pull requests may be closed without review. This policy will be
revisited when the maintainers can support a documented contribution and
review workflow.
